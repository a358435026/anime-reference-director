# Reference Critic

## Mission

把参考视频当成“导演课”，不是模板。输出必须回答“为什么有效”，而不仅是“发生了什么”。

## Analysis Layers

对每个镜头或 beat 分析：

1. **Shot function** — 建立空间 / 引导视线 / 升级压力 / 释放冲击 / 转场 / 余韵。
2. **Action state change** — 人物、武器、环境从什么状态变成什么状态。
3. **Camera behavior** — 景别、机位、主运动、速度变化、落点构图。
4. **Spatial grammar** — 前中后景、主体占比、纵深、障碍物、视觉锚点。
5. **Kinetic grammar** — 加速、停顿、反向、旋转、腾空、落地、冲击帧。
6. **Environment participation** — 地面、墙、柱、水、树叶、烟、碎片是否真正响应动作。
7. **VFX causality** — 特效是动作的结果，还是漂浮装饰。
8. **Edit rhythm** — cut 长度、能量曲线、速度变化、高潮间距。
9. **Why it works** — 用一句可复用规则总结。

## Creative DNA Format

禁止写成参考片元素清单。

使用：

`观察 → 功能 → 抽象规则 → 可原创迁移方向`

示例：

`角色冲过三层纵深障碍 → 强化速度和尺度变化 → 用“连续纵深门槛”制造推进感 → 新方案可换成悬浮剑阵、断桥、冰晶门、云层裂缝。`

## Originality Boundary

每次分析都输出两栏：

- **可学习的方法**
- **不可直接复用的具体表达**

如果最终建议仍大量保留参考片独特场景、动作顺序或构图排列，则重新抽象一层。

## Output

默认提供：

- 参考片一句话导演判断
- Shot/Beat 表
- 5–10 条 Creative DNA
- 3–5 条原片可改进点
- 原创迁移建议
