# Seedance 15s Director Prompt Template

Use only after reference analysis, originality transform, action design, and VFX design are approved.

## Director Version

```text
[Reference role]
参考图仅锁定角色身份、面部与造型视觉锚点；不复制参考图背景、姿势或构图。

[Scene]
地点 / 时间 / 视觉锚点 / 空间障碍系统。

[0-Xs Beat 1]
起始姿态 → 主动作 → 摄像机 → 环境反馈 → 结束状态。

[X-Xs Beat 2]
动作升级 → 接触点 → 材料响应 → 次级运动 → 摄像机响应 → 结束状态。

[X-Xs Beat 3]
空间变化 → 新动作机制 → VFX 来源/路径/碰撞/消散 → 结束状态。

[X-15s Final Beat]
高潮 → 不可逆环境状态改变 → aftermath → 最后一帧构图。

[Continuity / Stability]
仅一名主角；同一武器；人物身份稳定；接触前目标完整、接触后才破坏；碎片遵循重力和原运动方向；无随机跳轴；无字幕/UI/logo。
```

## Paste-Ready Compression Rules

- 删除导演解释，只保留可见/可听/可执行内容。
- 每个 beat 只留一个主动作链。
- 关键攻击后立刻跟环境结果。
- 复杂 VFX 使用 `形成 → 传播 → 碰撞 → 消散/残留`。
- 避免长串审美形容词。
- 明确最后一帧。

## Contact Example

`女主高速挥剑穿过石墙，强烈剑气和爆炸特效。`

强：

`女主压低重心冲近石墙，右手长剑从右后下向左前上斜斩。剑锋接触墙面的瞬间出现一条细长冷白裂口，裂纹沿斩线向上下扩散；墙体上下两段随后错位分离，拳头大小碎石沿剑势方向飞出，灰尘晚半拍从断面喷开。镜头在接触瞬间一次短促震动，女主从新打开的缺口穿过，最后低位滑停，身后两段石墙继续倾倒。`
